# سَنا — القرآن الكريم

موقع عربي متجاوب لقراءة القرآن الكريم، مبني بخادم Node.js بسيط يعرض الصفحات على الخادم، دون اعتماد على إطار عمل أو قواعد بيانات.

## التشغيل

يتطلب Node.js 20 أو أحدث:

```bash
npm start
```

افتح `http://localhost:3000`. لتشغيل اختبارات سلامة البيانات والصفحات:

```bash
npm test
```

يمكن تغيير المنفذ عبر `PORT`. عند النشر، اضبط `SITE_URL` على رابط الموقع العام النهائي، مثل:

```bash
SITE_URL=https://your-domain.example PORT=3000 npm start
```

استخدم نطاقك الحقيقي بدل المثال، وفعّل HTTPS في الاستضافة. الروابط الأساسية مثل `/surah/18` و`/sitemap.xml` تُنشأ على الخادم، وتتوفر إعادة توجيه من `/18.html` إلى صفحة سورة الكهف.

## ما يتضمنه الموقع

- السور الـ١١٤ كاملة، وصفحة مستقلة قابلة للفهرسة لكل سورة.
- البحث في السور والآيات، وعرض التفسير الميسّر عند الطلب.
- الاستماع إلى السور أو الآيات، وحفظ الآيات وآخر موضع قراءة محليًا في المتصفح، وتغيير حجم النص والمظهر.
- ملفات `robots.txt` وخريطة XML، وعناوين وأوصاف وروابط canonical وبيانات منظمة للصفحات. لا يضمن ذلك ترتيبًا معينًا في Google.

## المصادر والترخيص

- النص القرآني: **Tanzil Quran Text، Uthmani v1.1**. ملف المصدر `data/quran-uthmani.txt` من [مشروع تنزيل](https://tanzil.net/) كما هو، ويحتوي على إشعار الترخيص الكامل. يُفصل موضع البسملة عن الآية الأولى للعرض فقط دون تغيير حروف النص، مع الحفاظ على رسم البسملة الخاص في سورتي التين والقدر. راجع [شروط النص](https://tanzil.net/docs/text_license) والتحديثات قبل النشر.
- أسماء السور وبياناتها: [Quran.com API](https://quran.com/)، مع معلومات الأجزاء من [AlQuran Cloud](https://alquran.cloud/).
- التفسير: التفسير الميسّر عبر AlQuran Cloud عند الطلب. تلاوات السور تُبث من [MP3Quran](https://www.mp3quran.net/) وتلاوات الآيات من [EveryAyah](https://everyayah.com/)، ولذلك يلزم اتصال بالإنترنت. تأكد من شروط استخدام هذه الخدمات وحقوق التسجيلات قبل الإطلاق أو الاستخدام التجاري.
- الخطوط: Amiri Quran وIBM Plex Sans Arabic، وتوجد إشعارات ترخيص الخطوط في `public/fonts/`.

## قبل الإطلاق العام

1. اضبط النطاق النهائي في `SITE_URL` واختبر الصفحات على HTTPS.
2. اربط الموقع بـ Google Search Console وأرسل `https://نطاقك/sitemap.xml` بعد النشر، ثم راقب الفهرسة وتجربة الصفحات.
3. راجع المحتوى القرآني والتفسير ومصادر الصوت بصورة دورية مع مختص، وراجع تراخيص الخدمات الخارجية.
4. ضع خطة مستمرة لمحتوى مفيد وقياس الأداء وتحسين سرعة الموقع. التصدّر لا يمكن ضمانه، والفهرسة والترتيب يحددهما Google.

## النشر على Vercel

يتضمن المشروع `vercel.json` وواجهة `api/index.js` لتشغيل الخادم كدالة Vercel، مع الحفاظ على صفحات السور والبحث وخريطة الموقع. عند استيراد المستودع من GitHub إلى Vercel اختر إعدادات المشروع الافتراضية. بعد تعيين النطاق الإنتاجي، اضبط `SITE_URL` في إعدادات متغيرات البيئة على رابط النطاق النهائي وأعد النشر، لتوليد روابط canonical وخريطة موقع صحيحة. لا تتضمن هذه الملفات أي بيانات دخول.

## التحقق في Google Search Console

أضف `https://sana-quran.vercel.app/` كموقع من نوع **بادئة عنوان URL**، واختر طريقة **علامة HTML**. اضبط متغير البيئة `GOOGLE_SITE_VERIFICATION` على قيمة `content` من الوسم الذي يقدمه Google (أو على سجل `google-site-verification=...` كاملًا)، ثم أعد نشر الموقع. عند ظهور الوسم في الصفحة الرئيسية، اضغط «تحقّق» في Search Console وقدّم `https://sana-quran.vercel.app/sitemap.xml`. احتفظ بالمتغير بعد التحقق حتى يستمر Google في تأكيد الملكية. رمز التحقق يُعرض علنًا في HTML وليس كلمة مرور أو رمز تسجيل دخول.
